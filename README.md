# AxetosOS Vision — Redesigned website

A standalone responsive redesign of the AxetosOS vision page (November 2026).

## Preview

Open `index.html` in a browser. No build step, dependencies, external fonts, APIs or network requests are required for the website itself. External links lead to GitHub or an email client.

## Publish on GitHub Pages

1. Copy `index.html`, `styles.css`, `script.js` and the `assets` folder into your GitHub Pages repository (at its configured publishing root).
2. Commit and push.
3. Enable/confirm Pages deployment in the repository Settings → Pages.

If the site is published at `https://axetos.github.io/axetos-vision/`, its assets are all relative and need no path changes. This is a replacement site, not a modification to the remote repository; no repository files were changed on GitHub.

## Content notes

- Leads with the end goal: **build virtually any kind of software with the right Modules**.
- Replaces the abandoned five-layer model with a minimal CORE and composable Module concepts.
- Avoids the discontinued “Advanced Loader” terminology.
- Distinguishes foundational implementation, ongoing architecture and future goals.
- The interactive module handover is a **visual concept demo**, not a demonstration of production AxetosOS functionality.
- Extension of compiled products refers **only** to products explicitly built with AxetosOS support, not arbitrary third-party software.
- Review the project status text periodically as development progresses.

## Technical notes

- Responsive HTML/CSS/vanilla JavaScript.
- Navigation works with mouse, touch and keyboard; the explorer uses accessible tabs with arrow-key navigation.
- Respects `prefers-reduced-motion`.
- No third-party runtime dependencies.
